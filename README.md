# Geometry Drawing Lab

Учебное WPF-приложение на C# для рисования и перемещения геометрических фигур. Проект выполнен по заданию лабораторной работы № 0 и демонстрирует классы, агрегацию, ветки, атомарные коммиты и слияние.

## Возможности

- треугольник по трём введённым точкам или случайным координатам;
- прямоугольник по начальной точке, ширине и высоте или случайным значениям;
- квадрат с заданной или случайной стороной;
- очистка холста;
- перемещение активной фигуры по осям X и Y без выхода за границы холста — в ветке `feature/move-shapes` до завершения Pull Request;
- сообщения об ошибках для некорректных координат и размеров.

## Требования и запуск

- Windows 10/11;
- Visual Studio 2022 с компонентом **Разработка классических приложений .NET**;
- .NET 8 SDK.

Откройте `GeometryDrawingLab.sln`, выберите запускаемым проект `GeometryDrawing.Wpf` и нажмите `F5`.

Проверка из терминала Windows:

```powershell
dotnet restore
dotnet build GeometryDrawingLab.sln
dotnet run --project src/GeometryDrawing.Wpf
```

WPF работает только на Windows. Проект специально разделён на независимую модель `GeometryDrawing.Core` и графический интерфейс `GeometryDrawing.Wpf`.

## Основные классы

- `Point2D` хранит координаты и изменяет их методами `AddX` и `AddY`.
- `Triangle` агрегирует три объекта `Point2D`.
- `RectangleFigure` создаёт четыре вершины из начальной точки, ширины и высоты; фабричный метод `CreateSquare` создаёт квадрат.
- `IFigure` задаёт общий контракт фигур.
- `FigureMovement` безопасно перемещает фигуру внутри холста.

## Ветки лабораторной

- `main` — проверенная основа приложения;
- `feature/rectangle` — реализация прямоугольника, уже слитая в `main` merge-коммитом;
- `feature/move-shapes` — перемещение; её нужно отправить на GitHub и слить в `main` через Pull Request.

Подробные команды и рекомендуемое распределение работы между двумя участниками находятся в [docs/GIT-WORKFLOW.md](docs/GIT-WORKFLOW.md).
